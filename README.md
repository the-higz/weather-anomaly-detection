# Weather Anomaly Detection

Projeto de Iniciação Científica voltado à identificação de anomalias em dados meteorológicos da estação de Catalão (GO), utilizando técnicas de análise de dados e aprendizado de máquina.

## Objetivos

- Processar e organizar dados meteorológicos.
- Aplicar o algoritmo Local Outlier Factor (LOF) para identificar anomalias.
- Analisar as observações classificadas como anômalas.
- Exportar resultados para planilhas Excel.
- Disponibilizar um dashboard interativo para explorar os resultados.

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- OpenPyXL
- Streamlit
- Plotly
